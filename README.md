
# Portal Frontend Básico

## Descripción
Página web personal desarrollada con HTML y CSS
como parte de la asignatura Diseño de Sistemas en Internet.

## Tecnologías utilizadas
- HTML5
- CSS3

## Contenido
- Presentación personal
- Pasatiempos
- Lista de intereses y habilidades
- Enlaces a sitios web

## Cómo ejecutar el proyecto
Abrir el archivo index.html en un navegador web.
